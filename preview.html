Sashan — Phase 1 Preview

This file summarizes the Phase 1 scaffold created in this workspace so you can review it locally.

How to run

Install and run the Next.js dev server from the project root:

npm install
npm run dev

Set these environment variables in .env.local before running:

NEXT_PUBLIC_SUPABASE_URL=https://your-project.supabase.co
NEXT_PUBLIC_SUPABASE_ANON_KEY=anonkey
SUPABASE_SERVICE_ROLE_KEY=service_role_key

What was created

  • README.md — quick start and notes.
  • package.json — project manifest.
  • pages/index.js — homepage with Create/Join links.
  • pages/create.js — create lobby UI (calls /api/create-lobby).
  • pages/join.js — join/check lobby UI (calls /api/check-lobby).
  • pages/api/create-lobby.js — server API to create a lobby (uses Supabase service key).
  • pages/api/check-lobby.js — checks lobby existence and status.
  • db/migrations/001_init.sql — initial DB schema for lobbies and game state.
